Following a discussion with our project supervisor, we have tentatively selected the following eight mini-games as an initial draft for *Panic at the Terminal*. The list below outlines the core concept and mechanics of each proposed game.

| GAME NAME | DESCRIPTION |
| --- | --- |
| Anagram | Unscrambled jumbled letters to form the correct meaningful word. |
| Wordle | Guess a hidden 5-letter word within a limited number of attempts based on letter hints. |
| 24 math game | Use four given numbers and basic arithmetic (+,-,\*,/) to make the total equal exactly 24. |
| Reverse typing | Type a given word, code, or phrase backward within the time limit. |
| Quick directional reflex | Press random directional keys (all alphabets coming randomly) rapidly under strict time pressure like for 30 seconds. |
| Memory sequence | Memorize a flashed sequence of numbers, symbols, or patterns and recall it correctly. |
| Cipher Quest | Decode a secret message using a substitution or shift cipher to reveal the answer. |
| Safe crack | Guess a hidden target number using "Too High" or "Too Low" hints like a dial lock. |
